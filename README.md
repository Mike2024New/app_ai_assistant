## О проекте

app_ai_assistant — готовое приложение на базе экосистемы srv-сервисов.

### Что делает

- Слушает микрофон (через [srv_stt_vosk](https://github.com/Mike2024New/srv_stt_vosk))
- Понимает смысл через LLM (через [srv_llm](https://github.com/Mike2024New/srv_llm))
- Отвечает голосом (через [srv_tts_silero](https://github.com/Mike2024New/srv_tts_silero))

### Как работает

- Всё локально, без интернета, приватно (интернет требуется только на этапе установки для загрузки компонентов и сборки
  приложения).
- Стриминг на всех этапах, ответ начинает звучать с минимальной задержкой (зависит от модели и железа)
- Прерывание на лету — можно перебить ассистента новой фразой

### Для кого

- Тех, кому нужен приватный ассистент — разговоры останутся вашей тайной
- Возможно, поможет людям находящимся в одиночестве (например пожилые люди), ведь теперь можно поговорить со своим
  виртуальным другом, не боясь, что личные разговоры станут достоянием облачных сервисов.
- Тех, кто хочет максимально простую установку (установка для пользователя как обычный .exe а для разработчика сборка
  одной командой `python start.py`)

## Архитектура и технические фичи

Проект спроектирован как событийно-ориентированная микросервисная система:

1. **Потоковая обработка (Streaming Pipeline):** Интерфейс общается с сервисами через WebSockets и HTTP. Звуковой поток
   с микрофона (PCM) транслируется в STT, токены из LLM генерируются чанками, а TTS начинает синтезировать и
   воспроизводить речь попредложенчески. Задержка (latency) сведена к минимуму.
2. **Мгновенное прерывание (Interrupt on the fly):** Реализован конкурентный перехват промежуточных результатов STT (
   `type: partial`). Как только пользователь начинает говорить новую фразу, ассистент мгновенно сбрасывает текущую
   генерацию LLM и замолкает в TTS.
3. **Динамический оркестратор процессов:** Реализован автоматический поиск свободных портов для сервисов и менеджмент их
   жизненного цикла (PID-менеджер), предотвращающий зомби-процессы в ОС при аварийном завершении.
4. **Zero-Dependency Инсталлятор:** Отдельный модуль сборщика (.exe в релизе) автоматически разворачивает изолированный
   `portable-Python` и `MinGit`, параллельно через `asyncio.gather` собирает независимые виртуальные окружения (
   `.venv`), подтягивает зависимости через `uv`, скачивает тяжелые веса моделей и компилирует всё в бинарники, используя
   префиксы `\\\\?\\` для обхода системных ограничений Windows на длину путей (`MAX_PATH`).

## Быстрый старт (для разработчиков)

### 1. Клонирование

```bash
git clone git@github.com:Mike2024New/app_ai_assistant.git app_ai_assistant
cd app_ai_assistant
```

### 2. Создать виртуальное окружение

> Важно! Папка с виртуальным окружением должна называться `.venv`

```bash
# Windows
python -m venv .venv && .venv\Scripts\activate

# Linux
python3 -m venv .venv && source .venv/bin/activate
```

### 3. Установить зависимости

`python start.py` # автоматически подхватятся все зависимости с которыми работает пакет. А также будет выполнена сборка
exe/bin.

### 4. Установка сервисов

В корневую директорию необходимо установить сервисы (если установка выполняется через инсталлер из релиза то он делает
это автоматически), если вы ставите этот проект как разработчик то выполните инструкцию из репозиториев:

- [srv_llm](https://github.com/Mike2024New/srv_llm) - мозг приложения.
- [srv_tts_silero](https://github.com/Mike2024New/srv_tts_silero) - голос приложения.
- [srv_stt_vosk](https://github.com/Mike2024New/srv_stt_vosk) - уши приложения.
